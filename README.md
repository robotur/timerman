# timerman
Desk timer for locking in

*for HC Phantom*
# Overview
timerman is a desk timer with no distractions that you can customize however you want.

# Features
timerman has a customizable LCD menu, brightness & timer (multi function) knob, and a button for ui controls.
it's powered by a 18650 3.7v battery, boosted to 5v with a mt3608 module; and has usb-c charging using a tp4056 module.

# Why?
i'm making timerman because i think your EDC/peripherals should reflect your personality.
*here, i want a simple timer to show that i'm a maker.*

# How is timerman made?
timerman is esp32-s3 based; but you can use any microcontroller that can run a simple lcd screen;
you use what you have on hand, and that's the point.

i used a simple breadboard to wire the main components, hot glued them together, modeled & 3d printed a simple case and finally put it together.

# Required parts
*(you can swap any of these parts to your liking)*
 (battery, charger, booster, esp32, screen, pot, buttton)
 18650 3.7v Battery,
 TP4056 usb-c battery charger,
 MT3608 voltage buck booster,
 ESP32-S3R16N8,
 random LCD,
 B10K potentiometer,
 random button (i use gateron milky switches because i'm a keeb)
